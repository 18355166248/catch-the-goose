# 数据后的产品决策门槛

在达到 20 名玩家、每档至少 30 次有效结算前，默认决策是：不扩地图、不做排行榜、不重做经济系统。

| 观测结果 | 决策 | 下一轮 |
|---|---|---|
| 启动到首页 < 90% 或 runtime_error > 1% 会话 | 技术优先 | 修加载、兼容与资源；暂停内容开发 |
| 首页到开局 < 70% | 首页/引导优先 | 收敛选择成本，强化 CTA 与玩法说明 |
| 轻松关胜率 < 70% | 新手难度过高 | 放宽时限、减少遮挡或增强首局提示 |
| 标准关胜率 35%～65%，大师关 15%～40% | 难度梯度健康 | 保持核心数值，进入留存实验 |
| 大量 `round_exit` 且完成度 < 20% | 开局体验问题 | 查加载等待、堆形、首批可点性 |
| 救场后胜率仍低 | 救场无效 | 改退件策略，不增加更多免费次数 |
| 玩法完成健康但次日回访 < 15% | 缺留存理由 | 优先做轻量图鉴或每日目标 A/B 二选一 |
| 次日回访 ≥ 25% 且四主题消耗稳定 | 可扩内容 | 新机制/新主题择一，不同时铺开 |

排行榜只有在跨日回访已成立、且明确需要社交竞争时再建后端；否则投入与防刷成本高于收益。
