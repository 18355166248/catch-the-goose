# H5 真机验收清单

每台设备均从清空站点数据后的首次访问开始。结果必须记录设备、系统、浏览器、网络、日期与构建提交。

## 设备底线

- iPhone 8 或同级旧 iOS 设备，Safari。
- 骁龙 6 系中端 Android，系统 Chrome/WebView。

## 性能与稳定性

- 首屏：首页可交互耗时；开始挑战后模型可操作耗时。
- 三档难度落堆阶段与稳定阶段 FPS；底线为稳定阶段不低于 30 FPS。
- 连续完成或退出 3 局，观察内存、发热、掉帧是否持续恶化。
- 切后台 10 秒后恢复：计时不追赶、物理不炸堆、声音状态正确。
- 弱网/断网：远程站点框和勾章使用本地 fallback；资源失败时不能进入缺件关卡。

## 核心交互

- 首次引导 → 首页 → 四站切换 → 三难度切换。
- 开局 → 点击物件 → 三消 → 三个道具 → 冰封 → 金鹅。
- 暂停 → 继续、重开、声音开关、退出本局。
- 用完 3 次 → “再续一次” → 正常开局。
- 胜利/失败/救场/下一关；退出后再次开局无幽灵物件。
