## 构建处理

Windows 实测编辑器和 CLI 同时打开本工程会争用 `project.log` 与 Chromium 缓存。
构建工具现在要求 Windows 在导入完成后保存并关闭本工程编辑器，再独立执行 CLI；
macOS 保留仓库原有的“编辑器打开本工程”前提。已有构建运行时，后续构建会提前退出。

保留 release/WASM、关闭 MD5/source map、Jolt 固定文件、玩法脚本非空及 20 MiB 门禁；
清理构建目录前检查真实路径。构建错误仍返回非零退出码。
Creator 返回码 `36` 按[官方命令行文档](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/publish-in-command-line.html)
作为成功处理，并继续检查日志与产物。

最终构建通过，目录大小 **18.94 MiB**。日志：`game/temp/web-mobile-build.log`。
