## 生成方式

- 工具：内置 imagegen。
- 参考图：`challenge-map-bg.jpg`（既有美术语言）与 `map-route-extension.jpg`（河流、石径和纵向构图）。
- 核心提示：生成一张约 1:3 的连续手绘童话地图；路线由底部水果野餐，经古玩铺、池塘农场，
  到顶部甜品村；四个生境通过同一条河流和奶油色石径渐变连接；只保留整张地图最外层羊皮纸
  边缘；禁止文字、编号、角色、内部边框、桌布横条、横向海岸线、重复段和可见拼接。
- 站点组件提示：生成空白的手绘奇幻游戏站点底座，上部是胡桃木与古金圆形章牌，下部是米白羊皮纸名牌，
  带关卡号插槽；禁止文字和图标，使用高饱和品红背景便于去底。运行时稿使用 imagegen 自带的 chroma-key 脚本转为透明 PNG。
- 圆章画芯提示：四枚童话浮雕收藏章，大主体配少量环境背景；水果篮为苹果野餐篮，古玩铺为玉狮与暖灯店面，
  农场为池塘白鸭与红谷仓，甜品小镇为草莓奶油蛋糕屋。运行时只截取圆形画芯，去除生成稿自带木框，避免与组件底座出现双框。
- 选中徽章提示：古金圆形勋章、祖母绿珐琅勾与米白绶带，在 36–48px 仍清楚；品红底生成后使用 chroma-key 脚本转透明 PNG。

## 使用约束

- 站名、站号、选中态与点击热区由 `HomeScreen.ts` 叠加，禁止烘焙进底图。
- 四站共用同一站点底座；通过完整主题画芯和文案区分，四张画芯保持相同 98×98 显示尺寸与 `(0, 39)` 圆心，选中态只使用静态金色光圈。
- 叠加坐标一律以底座源图（1448×1086，显示 330×247，缩放 0.2279）量出来的圆心为准：
  主圆章内芯直径 459px、圆心 (721.5, 371) → 显示直径 105、圆心 `(0, 39)`；
  左下站号槽内芯圆心 (224, 800.5) → 显示 `(-114, -58.5)`。别再凭手感微调。
- 选中光圈直径贴合主圆章内芯，并且必须画在底座之后：底座内芯不透明，先画会被整块盖住，
  只剩超出木框的一段弧露在画芯上方。
- 站点选中态使用常驻金圈和手绘绿勾章；非选中项整体降到 190/255 透明度。选中项不缩放、不回弹、不播放扩散涟漪。
- 难度选中态使用原切图高亮、托底辉光和同款绿勾章；切换时同步换透明度与位置，不做交叉淡入或弹跳。
- 后续增加第五站时应重新扩展连续长卷，不再恢复“完整图片上下堆叠”的方案。
