# Chinese guardian lion — source attribution

This work is based on [Chinese guardian lion](https://sketchfab.com/3d-models/chinese-guardian-lion-afdb632cc23f4c0c9bbaa1100010039f)
by [rvscanners](https://sketchfab.com/rvscanners), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Project modifications:

- combined the segmented Sketchfab glTF meshes;
- reduced polygon density for real-time rendering;
- normalized scale and orientation for use as an imperial-seal knob;
- replaced the source appearance with the project's warm nephrite-jade material;
- integrated the sculpture with a newly created seal body and decorative collar.

The untouched downloaded files remain under `original/` in the local workspace. Their large
binary payload is intentionally excluded from Git; download the official glTF archive from the
linked Sketchfab model before rerunning the preparation script. The processed game intermediate,
this attribution, and the deterministic preparation script are versioned with the project.
