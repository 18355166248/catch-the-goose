# 模型质量基线与精修记录

统一使用 `scripts/render_model_audit.py` 的近俯视相机、三点布光和透明背景渲染，避免用
Blender 编辑视图、文件体积或单张图标替代游戏视角判断。`scripts/compose_model_audit.py`
将逐件结果组成主题对照表。

后续 26 个模型统一执行 [3D 模型质量升级 v2 规范](../../docs/model-quality-v2-playbook.md)，
其中包含苹果流程、逐模型门禁、Cocos 导入约束、完成定义和跟踪表。本文件继续记录实际结果，
不再重复维护流程规则。

## 2026-08-20 结论

- 古玩铺完成度最高：材质高光、轮廓差异和装饰层次已经形成统一语言，暂不重做。
- 水果摊是首个主题，也是原先最明显的短板：苹果和橙子接近光滑球，香蕉只有单色管状
  几何，梨由三段球拼接，草莓过尖。已完成第一轮整组精修。
- 池塘农场在基础细节补齐后，又重做了青蛙、锦鲤、莲花和鸭子的主体轮廓、姿态、
  配色与表情，固定机位下的角色辨识度更高。
- 甜品小镇九件模型已完成整组生动化：增加烘烤层次、糖霜装饰、颗粒裙边、奶油与
  果粒等细节，同时保持统一的圆润低多边形语言。
- 游戏运行时已有暖主光、环境补光和平面投影。本轮没有为了制造“更亮”的假提升改动
  全局灯光，避免真机上高光过曝和主题背景色偏移。

## 水果第一轮改动

- 苹果：五瓣自然轮廓、顶部凹窝、加大果梗与叶片。
- 香蕉：两端深色果蒂、顶部暖色纵向高光脊，保留原有弯曲主轮廓。
- 橙子：轻微七瓣起伏、顶部压窝、外露果梗与叶片。
- 草莓：重做圆润心形轮廓、18 颗贴合表面的浅金种子、统一六片绿萼材质。
- 梨：由三段 metaball 改为连续单皮网格，并补叶片。
- 柠檬：保留两端尖角并增加可从俯视看见的叶片。
- 樱桃：增加两梗交汇处叶片。
- 葡萄：原有成串轮廓与材质层次已经合格，本轮只重新渲染匹配的新图标。

所有水果仍归一化为最大边 1.0；第一轮单件不超过 1.75k 三角面。苹果 v2 为加强顶窝、
折叶和弯梗提高到约 2.5k，仍处于移动端轻量模型预算内。

## 苹果 v2 设计稿重建（2026-08-22）

用户复核认为原苹果仍像光滑圆球，因此使用 `img2threejs` 的“参考图评估 → 严格雕刻规格 →
多角度验收”流程单独重建。设计稿保存在
`design/fruit-theme/apple-v2/apple-concept-sheet-v1.png`，严格规格保存在同目录的
`apple-sculpt-spec.json`。

- 主体改为连续五瓣体块，增加真实顶窝、肩部起伏和收窄底部，不再依赖侧面贴片制造变化。
- 果梗改为从顶窝内部起步的弯曲渐细结构，并增加独立切面。
- 叶片改为有厚度和中折的三列截面网格，补充独立主叶脉；侧面和背面都保持可读。
- GLB 保留 `fruit-body`、`stem`、`leaf` 三个语义部件，统一归一化后导出；最终约 2.5k
  三角面、6 个材质、83 KB。

固定机位前后对比保存在 `audit/model-quality/apple-v2/before-after.png`，另有 `side` 与
`back` 两个旋转机位。三个角度均未发现悬浮部件、破面或材质黑块。

## 农场与甜品第一轮改动

- 农场：胡萝卜增加四道浅横纹；玉米改为错列凸起粒阵；南瓜使用交替明暗分瓣；蘑菇
  斑点贴合伞盖表面。
- 甜品：马卡龙用两圈低面数颗粒形成不规则裙边；曲奇增加烘烤边和三道裂纹；蛋糕切片
  增加奶油珠与第二颗莓果。
- 第一轮审计结果中，农场除南瓜约 3.2k 三角面外均不超过约 2.3k；甜品除可颂约 2.9k
  外均不超过约 2.1k。后续重点模型重做后的最新预算见下节。

## 第二轮生动化改动

- 苹果增加贴合果皮的暖色红晕；橙子增加稀疏表皮气孔；梨增加同色浅斑；柠檬补齐两端
  深色果蒂。所有表皮细节均使用低面数几何，随机旋转后仍能从部分角度看到自然变化。
- 茄子增加细长釉光；鸭子补充翼羽、尾羽、眼睛高光和脸颊，使动物表情更完整。
- 冰淇淋蛋筒增加四道低面数烘烤环纹；马卡龙增加同色外壳釉光；布丁增加焦糖滴落、
  奶油旋涡和樱桃；可颂改为深浅烘烤分段并增加少量黄油亮面。
- 复核时撤回了会读成凸钉、贴纸或悬浮件的早期方案。最终冰淇淋约 1.6k、布丁约 1.8k、
  马卡龙约 1.95k、可颂约 2.9k 三角面，细节与移动端预算保持平衡。

## 第三轮重点模型重做

- 青蛙改为完整蹲坐姿态，补齐鼓眼、瞳孔高光、脸颊、微笑、前肢、后腿与脚趾；约
  2.9k 三角面。
- 锦鲤使用珍珠白主体、橙红斑块和红色鳍尾，增加背鳍、立体鳞片、眼睛高光与嘴部；
  约 2.0k 三角面。
- 莲花增加荷叶底座、叶脉和三圈深浅花瓣，中心改为小型莲蓬与十二组花蕊；约 3.9k
  三角面。
- 鸭子重构正面可读姿态，增加胸腹层次、双翼羽片、尾羽、眼睛高光、脸颊与脚掌；约
  2.7k 三角面。
- 甜品整组继续细化：纸杯蛋糕增加杯纸棱和糖针，甜甜圈增加彩糖针，冰淇淋强化蛋筒
  烘烤纹和糖浆滴落，马卡龙增加裙边与壳面气孔，曲奇加强烘烤边，蛋糕增加夹层、奶油
  珠和莓果，糖果增加条纹与包装束带，布丁保留焦糖滴落与奶油樱桃，可颂强化焦褐渐变
  和层压接缝。

## 青蛙与鸭子设计稿重建

用户复核认为第三轮青蛙和鸭子仍然不够美观，因此不再沿用原有横向趴卧/面包形比例。
先用内置 imagegen 生成 `design/farm-theme/concepts/frog-duck-character-sheet-v1.png`，再按稿
提取可程序化实现的大形：青蛙为头身融合的直立梨形坐姿，鸭子为独立圆头与直立圆身；
两者都用奶油色眼白、棕色虹膜、黑色瞳孔和独立高光构成完整眼睛。

最终评分门槛提高到 9.0：青蛙 9.1，鸭子 9.2。提交的固定机位主题成图保存在
`audit/model-quality/final/_sheet_farm.jpg`；逐件 PNG 可用下方审计命令随时重新生成。

以上改动仍保持物件最大边归一化为 1.0，并沿用现有碰撞生成方式。

## 复核方式

```powershell
& 'C:\Program Files\Blender Foundation\Blender 4.5\blender.exe' --background `
  --python scripts/render_model_audit.py -- --output audit/model-quality/current
python scripts/compose_model_audit.py --input audit/model-quality/current
```

审计脚本会为每件 GLB 输出三角面、材质数和归一化包围盒；主题表只作为固定机位的视觉
对照，最终仍应以真机堆叠场景里的可读性为准。

## 堆叠呈现优化

`GameManager.ITEM_SCALE_MULTIPLIER` 为细长或像素占比偏小的模型提供 4%~8% 的物理与视觉
同步放大；新设计稿重建的青蛙和鸭子使用 7% 补偿。`SIDE_PROFILE_TILT` 让草莓、梨、胡萝卜、
玉米、茄子和冰淇淋以更容易看清侧面轮廓的角度入筐，也让青蛙与鸭子保持能同时看到正脸、
腹部和脚掌的温和倾角。圆盘和环形物件统一复用 `ROUND_ITEMS` 限制初始倾角，避免新增主题
时只维护碰撞分类、遗漏朝向分类。所有补偿都参与 Jolt 代理尺寸计算，不会产生模型变大但
点击或碰撞范围仍旧偏小的问题。
