# 玉扳指 v2 验收记录

## 旧版问题

- 主体是低信息量的深绿圆筒，缺少玉石的棉絮、色根和透润层次。
- 通孔与内壁关系单薄，固定俯视机位下容易读成普通杯筒。
- 色彩与古玩铺其他深色模型接近，堆叠后辨识度不足。

## v2 结果

- 使用真实连续通孔、厚壁桶形和不对称斜口重建主体，保持扳指语义。
- 512×256 连续贴图分别提供浅青玉底、乳白棉絮、青绿色根与单侧糖沁；粗糙度和微法线使用独立贴图。
- 弱自透亮响应只托起固定顶光下的死黑暗部，不依赖透明材质，避免 Cocos 堆叠场景中消失。
- 内壁使用开口淡香槟金衬层，正面山云纹由青玉粗线和克制金色山脊构成。
